**Recommendation: confirmed, Melee via Slippi, first family wavedash, with L-cancel as the paired telemetry-only control.** Slippi is the only adapter that combines pilot coverage, frame-exact state for validating candidates, and renders the user can produce with an explicit frame map. Wavedash is defined by three short transitions (jumpsquat → airdodge → special landing). These are checkable in telemetry and visible only if native-rate frames are kept, which directly tests the frame-selection rule. L-cancel is the designed case where the visual arm should answer INSUFFICIENT. AoE is deferred because it has no validator and its terms are long-horizon.

## Stage 2 rationale (short)

- **Six cells, one example.** All six cells are paired on the same example, so the jargon − plain difference is within-example. Wording changes only the final question block. Frames and text evidence come first, identical across arms, which also gives a cacheable prefix.
- **Properties in a separate request.** Property keys effectively define the mechanic, so asking them in the same request would leak a definition into the jargon arm. Request B uses neutral questions shared by both wordings.
- **Frame selection.** Keep every native frame at 64 or fewer; otherwise subsample uniformly but always keep each key frame and its predecessor. This prevents erasing 1–4-frame transitions such as jumpsquat → airdodge.
- **Seeds.** Closed APIs here have no sampling seed. Seeds 11/23/37 fix label-option order and request order; the three replicates measure nondeterminism.
- **Reference points.** B0 is the label prior. B1 is a frozen CLIP-class probe on the same frames (vision without language). B2 is the telemetry rules: an information reference using privileged state, not a visual upper bound. Annotators are blinded to rule outputs to limit circularity.
- **Cost (configured scenario, not a quote; 150 eval episodes, 4,050 requests per model, no cache/batch).** Claude Opus 5.5 ≈ $356 (cap $473), Sonnet 5.5 ≈ $178 (cap $237), Haiku 5.5 ≈ $9 (cap $12). With a shared cached frame prefix: ≈ $112 / $56 / $3. The dev smoke run is about one third of that. OpenAI/Gemini are unpriced. The image tokens per frame and the images-per-request limit are the biggest unknowns.
